\section{Условие}

\subsection{Цель работы}
Приобретение практических навыков в:
\begin{itemize}
    \item Создание динамических библиотек
    \item Создание программ, которые используют функции динамических библиотек
\end{itemize}

\subsection{Задание}
Создать динамические библиотеки, реализующие заданный вариантом функционал. Использовать данные библиотеки двумя способами:
\begin{enumerate}
    \item Во время компиляции (статическое связывание)
    \item Во время исполнения программы (динамическая загрузка)
\end{enumerate}

\subsection*{Вариант} 12

В работе должны быть представлены:
\begin{itemize}
    \item Динамические библиотеки, реализующие заданные контракты
    \item Программа №1, использующая библиотеку на этапе компиляции
    \item Программа №2, загружающая библиотеки во время выполнения
\end{itemize}
